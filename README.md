created using various programming languages
It is recommended for stable versions to use JavaScript CJS. 

| Language | File | Status | Dependencies | How to walk |
|--------|------|--------|--------------|-------------|
| **JavaScript (CJS)** | `JavaScript/zcli.cjs.js` | ✅ Stable | Node.js | `node zcli.cjs.js` |
| **JavaScript (ESM)** | `JavaScript/zcli.esm.js` | ✅ Stable | Node.js + ESM | `node zcli.esm.js` |
| **Python** | `Python/zcli.py` | ✅ Stable | Python 3.6+ | `python3 zcli.py` |
| **Bash** | `Bash/zcli.sh` | ✅ Stable | curl, jq | `bash zcli.sh` |
| **TypeScript** | `TypeScript/zcli.ts` | ✅ Stable | Node.js, ts-node | `ts-node zcli.ts` |
| **Go** | `Go/zcli.go` | ✅ Stable | Go 1.16+ | `go run zcli.go` |
| **Rust** | `Rust/src/main.rs` | ✅ Stable | Rust + Cargo | `cargo run` |
| **Java** | `Java/ZCLI.java` | ✅ Stable | Java 11+ | `java ZCLI.java` |
| **C** | `C/zcli.c` | ✅ Stable | GCC + libcurl | `make && ./zcli` |
| **C++** | `C++/zcli.cpp` | ✅ Stable | g++ + libcurl | `make && ./zcli` |
| **C#** | `CSharp/ZCLI.cs` | ✅ Stable | .NET 6.0+ | `dotnet run` |
| **Ruby** | `Ruby/zcli.rb` | ✅ Stable | Ruby 2.5+ | `ruby zcli.rb` |

### Clone Repository

```bash
git clone https://github.com/zax-universe/zai-cli.git
cd zai-cli
```

open the folder according to the desired language, for example:
```bash
cd Javascript 
node zcli-cjs.js
```
